# Sistema de Gestión de Reportes 🚨

Aplicación web desarrollada en Python (Streamlit) para la captura, clasificación y gestión de reportes de riesgo y atención ciudadana.

## Características
*   **Roles de Usuario:** Vistas separadas para captura (operador) y gestión (admin).
*   **Categorización Estricta:** GR1 (Vivienda en riesgo), GR2 (Deslave), GR3 (Socavón), GR4 (Seguimiento).
*   **Base de Datos:** SQLite integrada.
*   **Exportación:** Descarga de reportes a formato Excel.

## Uso Local
1. Clonar repositorio: `git clone [URL]`
2. Instalar dependencias: `pip install -r requirements.txt`
3. Ejecutar: `streamlit run app.py`
